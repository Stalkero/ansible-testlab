# ansible-testlab
Repo for learning ansible
This is all what you need to create your own test lab for ansible home lab

## Few specifications
- `VirtualBox` - The VM hypervisor for setting up the lab
- `ansible@ansiblehost` - The host machine for ansible server 
- `worker@ansibleworker1` - The worker node which we would manage with the host VM


## IP addresssing scheme
- `192.168.1.110` - Ansible host server
- `192.168.1.111` - Worker node

# Files / Folders naming information
- `ansible-prep.md` - Instruction how to install and prepare your hosts as well as node for ansible
